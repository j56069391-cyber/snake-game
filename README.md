# Snake

A classic Snake game in a single HTML file. No dependencies, no build step.

## Play

Open `index.html` in any browser, or serve it locally:

```bash
python3 -m http.server 8000
```

then visit http://localhost:8000.

## Controls

- **Arrow keys** or **WASD** to move
- **Swipe** on touch devices

## Features

- Score + persistent best score (localStorage)
- Speeds up gradually as you eat
- Self-collision and wall detection
- Works on desktop and mobile
